КАК МЫ ДЕЛАЕМ РОЛИКИ (канал «Красная нить», TikTok @nitka.stories и YouTube Shorts)

Что это: короткие вертикальные мультфильмы 9:16 (1080x1920, 30 к/с), сделанные целиком кодом.
Форматы: страшные истории-сериалы («Курьер уже внутри»), «Что если…», реальные истории через одну мелочь.

ИНСТРУМЕНТЫ
Remotion (React + TypeScript) рисует сцены, субтитры и рендерит MP4.
Python + ffmpeg сводят звук (громкость -14 LUFS).
faster-whisper даёт время каждого слова в озвучке, по нему двигается вся картинка.
Lumean API (шлюз к ElevenLabs): голос рассказчика Николай и звуковые эффекты.

КОНВЕЙЕР ОДНОГО РОЛИКА
1. Сценарий -> lines.json: строки для голоса (без тире, числа словами, у строки пауза gap).
2. Озвучка: весь текст одним заказом в ElevenLabs (Николай, модель eleven_multilingual_v2, stability 0.55).
   Whisper размечает время каждого слова -> voice.json.
3. Паузы под события (удары, скримеры) вставляются в тишину между строками отдельным скриптом,
   время всех слов сдвигается само.
4. Сцены: файл ролика на TypeScript. Всё время берётся из голоса (функции W('слово') и L(номер строки)),
   поэтому после переозвучки ничего не съезжает. Декорации (квартира, дверь, телефон, шкаф, лица) это
   React-компоненты из SVG: плоская 2D графика, холодная палитра, свет от экрана телефона.
5. Звук: cues.json, события привязаны к словам ("@шкаф+0.2" или "line:4-0.1"). Скрипт сводит голос, фон
   комнаты, низкий гул и эффекты. Эффекты всегда тише голоса, скримеры на уровне голоса, коротко,
   после них тишина.
6. Проверка: сначала рендерим стоп-кадры ключевых моментов и смотрим их, потом весь ролик.
7. Рендер MP4, затем ffmpeg: H.264 + AAC с лимитером.
8. Обложка 1080x1920: отдельным фото для TikTok и последними кадрами в видео для YouTube.
   В конце ролика карточка-вопрос с выбором «1 или 2» и «Подпишись».

ПРАВИЛА КАНАЛА
Один голос рассказчика (Николай), весь текст одним заказом, тише или громче только обработкой.
Крючок в первую секунду: сразу сцена и фраза, без тишины и заставок.
Новая часть серии начинается с последнего кадра прошлой.
Правило мира объявлено в первой части; одна новая загадка на часть; не больше 4 скримеров,
каждый на конкретной картинке.
Смысл: у каждой фразы понятна причина, время и откуда герой это знает. Цифры понятные на слух.
Никаких тире в текстах, субтитрах, обложках и описаниях.
Описание: название ролика и хештеги, максимум один вопрос по теме («А что бы сделал ты?»). Сюжет не пересказываем.
Субтитры по 1-4 слова, текущее слово в плашке; всё важное в безопасной зоне TikTok.
Палитра холодная, красный только на ключевых деталях. Длина 60-100 секунд, хоррор до 2 минут.

Ролик (TypeScript, Remotion), основа:
import voice from './vnutri2r.voice.json';
const L = (i) => voice.lines[i];                       // строка озвучки
const W = (w, from = 0) => voice.lines.slice(from)     // время слова
  .flatMap((l) => l.words).find((x) => x.w.toLowerCase().startsWith(w)).t;
const cut = (i) => L(i).start - 0.1;                   // склейка чуть раньше строки
const SCR = L(24).end + 0.25;                          // скример после последней фразы
export const Vnutri2R = () => {
  const t = useCurrentFrame() / 30;
  return (<AbsoluteFill>
    <Audio src={staticFile('vnutri2r/mix.wav')} />
    <Cut t={t} from={0} to={cut(2)}>                   {/* сцена 1: коридор, шкаф дрожит */}
      <Corridor t={t} wardrobe={1} shake={pulse(t, 0.05)} />
    </Cut>
    <Cut t={t} from={cut(2)} to={cut(3)}>              {/* сцена 2: вид из щели шкафа, REC */}
      <SlitPOV t={t} gap={0.45} rec><Room t={t} hero={{}} /></SlitPOV>
    </Cut>
    {/* ... остальные сцены так же, по словам и строкам ... */}
    <CaseSubs lines={voice.lines} />                   {/* субтитры по словам */}
  </AbsoluteFill>);
};

ПРИМЕР ГОТОВОЙ СЕРИИ «Курьер уже внутри»
Часть 1: в 23:47 приходит заказ, которого ты не делал. Три стука, за дверью никого, термопакет с завтрашней
датой, внутри старый телефон с видео, снятым из-за твоей спины. Курьер в уведомлении: это ты.
Часть 2 «Кто снимал»: видео снимали из шкафа; телефон показывает прямой эфир на 3 секунды вперёд;
дверца открывается, внутри ты сам в куртке курьера: «Твоя смена».
Часть 3 «Смена»: петля замыкается, ты сам стучишь в свою дверь, тебя никто не видит, ты прячешься в шкаф
и снимаешь себя же; сзади кто-то шепчет «Подвинься».
