# Спросить ChatGPT

Вопрос уходит в ChatGPT через Codex CLI (`codex exec`), который вошёл в аккаунт пользователя ChatGPT (Pro).
Ключ API не нужен: запросы расходуют лимиты подписки пользователя на Codex.

## Как спросить

```bash
bash .claude/skills/ask-chatgpt/scripts/ask.sh "вопрос" [файл ...]
```

- Файлы вставляются в запрос текстом (до 60 КБ каждый, переменная `MAX_BYTES`).
- Codex работает только на чтение (`--sandbox read-only`), сессию не сохраняет (`--ephemeral`), файлы проекта не меняет.
- Скрипт печатает только итоговый ответ ChatGPT.
- Модель по умолчанию из настроек Codex; другую можно задать `CHATGPT_MODEL=...`.
- Ответ обычно приходит за 10…60 секунд; длинные запросы запускать с таймаутом побольше.

Примеры:
```bash
bash .claude/skills/ask-chatgpt/scripts/ask.sh "Проверь сценарий на смысловые ошибки и выдумки. Ответ списком." docs/sleep-deprivation/script.md
bash .claude/skills/ask-chatgpt/scripts/ask.sh "Предложи 5 названий для ролика, без тире."
```

## Правила

1. Никогда не отправлять секреты: ключи, токены, пароли, содержимое `.env`, файлы `~/.codex`.
2. Перед отправкой сказать пользователю, что именно уходит в ChatGPT (вопрос и список файлов).
3. Ответ ChatGPT показывать как мнение ChatGPT, отдельно от своих выводов. Не выдавать его за факт: проверять
   спорные утверждения по источникам, особенно медицинские и научные.
4. Не принимать решения за пользователя по ответу ChatGPT: предлагать, что из ответа стоит применить.
5. Правила канала действуют и для текстов от ChatGPT: без тире, числа понятны на слух, один рассказчик (CHANNEL.md).

## Если не работает

- `Codex CLI не установлен`: `npm install -g @openai/codex` (с разрешения пользователя).
- `Codex не авторизован`: облачный контейнер временный, в новой сессии вход нужно повторить.
  Запустить `codex login --device-auth` в фоне, прочитать из вывода ссылку (https://auth.openai.com/codex/device)
  и одноразовый код, показать их пользователю; он открывает ссылку, входит в ChatGPT и вводит код.
  Пароль и токены в чат не просить. Проверка: `codex login status` → «Logged in using ChatGPT».
- Ошибка лимитов: исчерпаны лимиты подписки на Codex; сказать пользователю, когда они обновятся (из текста ошибки).
