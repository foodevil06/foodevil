# Маскот «Нитка» — на паузе (30.10.2026)

Решение: пока делаем ролики без маскота (серьёзнее, шире темы). Всё сохранено здесь, чтобы вернуть, когда понадобится.

## Что тут лежит
- `MASCOT.md` — паспорт: внешность, характер, правила, где маскот уместен (гибрид: после крючка и в финале).
- `src/Nitka.tsx` — риг с актёрской игрой (18 эмоций, тейки, значки, рот под голос, нить из руки, нуарный режим).
- `src/Mascots.tsx`, `src/MascotConcepts.tsx` — три первых варианта (Нитка, Полночь, Архивариус).
- `src/NitkaTest.tsx` + `nitka_test.*.json` — тест 7,6 с на доске улик.
- `src/BinanceHeist.with-mascot.tsx` + `binance.nitka*.json` — «Ограбление века» со вставками (гибрид).
- `out/binance_heist_hybrid.mp4`, `out/nitka_test.mp4` — готовые ролики для сравнения.

## Как вернуть
1. `Nitka.tsx`, `Mascots.tsx` → `src/toon/rig/`; эпизоды и json → `src/toon/episodes/`; `MASCOT.md` → корень.
2. Зарегистрировать композиции в `src/Root.tsx` (NitkaTest, MascotConcepts).
3. Вставки в ролик: `python scripts/insert_mascot.py …` (раздвигает голос рассказчика и сдвигает тайминги),
   рот: `python scripts/mouth.py …`; пример подключения — `BinanceHeist.with-mascot.tsx` (NitkaInsert + общие субтитры).
4. Скилл игры персонажа `cartoon-acting` остаётся установленным.
