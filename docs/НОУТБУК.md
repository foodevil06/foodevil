# Производство на ноутбуке

Ноутбук MSI Katana 17 B13V: i7-13620H (10 ядер, 16 потоков), RTX 4060 Laptop 8 ГБ, 16 ГБ ОЗУ, Windows.

Зачем переносим из облака:
- рендер в разы быстрее (в облаке 95 секунд видео рендерились 48 минут на 4 потоках без видеокарты);
- YouTube открывается нормально: можно покадрово разбирать ролики конкурента;
- твои браузеры, где уже открыты TikTok и VK;
- вход в ChatGPT (Codex) сохраняется, не надо входить заново в каждой сессии;
- облачная среда временная, ноутбук нет.

## Установка, один раз (около 20 минут)

1. Открыть PowerShell (обычный, не от администратора).
2. Скачать и запустить установщик из репозитория:
   ```powershell
   cd $HOME
   curl.exe -L -o setup_windows.ps1 https://raw.githubusercontent.com/foodevil06/foodevil/claude/kurier-part2-voiceover-mqiv7l/scripts/setup_windows.ps1
   powershell -ExecutionPolicy Bypass -File setup_windows.ps1
   ```
   Если репозиторий закрытый и ссылка не скачивается, открой файл `scripts/setup_windows.ps1` на github.com,
   нажми Raw и сохрани как `setup_windows.ps1` в папку пользователя.
3. Скрипт сам ставит через winget: Git, Node.js, Python 3.12, ffmpeg; клонирует проект в `%USERPROFILE%\foodevil`
   (Git попросит войти в GitHub в браузере); ставит зависимости, Claude Code и Codex CLI.
4. Ключ озвучки: в папке проекта создать файл `.env` с одной строкой `LUMEAN_API_KEY=...` (свой ключ Lumean).
   Файл `.env` в git не попадает. Ключ никому не присылать, в чат тоже.
5. ChatGPT: в PowerShell выполнить `codex login` и войти в свой аккаунт ChatGPT в браузере.
6. Проверка скорости: скрипт в конце рендерит ролик про сон и пишет время. В облаке было 2 894 секунды.

## Как работать дальше

- **За ноутбуком:** приложение Claude Desktop (claude.ai/download), раздел Code, папка `%USERPROFILE%\foodevil`.
  Или в PowerShell: `cd $HOME\foodevil` и `claude`.
- **С телефона:** в папке проекта запустить `claude remote-control`; сессия появится в приложении Claude Code,
  и можно писать ей с телефона, пока ноутбук включён.
- **Первое сообщение новой сессии:** «Прочитай КАК_МЫ_РАБОТАЕМ.md, docs/strategy/ и docs/НОУТБУК.md. Продолжаем план».
- Ноутбук может рендерить ночью: рендер идёт с низким приоритетом, ноутбук остаётся рабочим.

## Если рендер медленный

- В Windows: Параметры, Система, Дисплей, Графика: добавить `chrome-headless-shell.exe` из папки
  `node_modules\.remotion` и выбрать «Высокая производительность» (видеокарта NVIDIA).
- Потоки рендера: переменная `TOON_THREADS` (скрипт ставит 8). При 16 ГБ памяти больше 10 не ставить.
- Ноутбук должен быть на зарядке: от батареи видеокарта и процессор замедляются.
