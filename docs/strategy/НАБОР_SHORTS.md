# Набор Shorts на герое A

Код: `src/toon/style/ShortKit.tsx`. Показ: композиции `ShortKitSheet` (все детали стоп-кадрами) и `ShortKitDemo`
(немой ролик 22 с с грамматикой Short, `out/shortkit_demo.mp4`). Картинки: style/набор_shorts_1.jpg,
style/набор_shorts_2.jpg, style/демо_short.jpg.

```
node scripts/render.mjs stills ShortKitSheet out/kit 50 110 170 230 290 350 410 470 530
node scripts/render.mjs render ShortKitDemo out/shortkit_demo.mp4
```

## Что внутри

| Деталь | Что это | Как вызвать |
|---|---|---|
| `HeroA` | герой A: эмоция, поза, сам моргает и дышит | `<HeroA id="h" t={t} x={640} y={1180} emo="scared" pose="phone" />` |
| 10 эмоций `EMO` | calm, smile, alert, scared, terror, suspicious, angry, sad, tired, shock | `emo="terror"` |
| 12 поз `POSE` | none, down, phone, phoneEar, listen, shush, stop, mouth, reach, hold, mug, shrug | `pose="listen"` |
| 3 вида `mode` | `normal`; `shadow` (силуэт B: страшный момент); `xray` и `split` (рентген C и скан: «изнутри») | `mode="split" scan={560}` |
| Декорации | `Bedroom` (шкаф приоткрыт, глаза в щели, телефон), `Landing` (подъезд: дверь 47, лестница, мигающая лампа, ноги сверху), `Kitchen` (холодильник со светом, чайник), `Hallway` из StyleKit (входная дверь, домофон) | в `WorldCam`, камера `camAt` |
| `ThreadProgress` | прогресс сверху: красная нить через булавки; правила 1…4 или время 0 Ч, 24 Ч… | `steps={['1','2','3']} at={[t1,t2,t3]}` |
| `TopChip` | плашка-суть 2…5 слов, слово в звёздочках красное | `text="ШАГИ *СВЕРХУ*"` |
| `Clock`, `Bubble`, `Mark`, `FactTag` | красное время, реплика (герой, другой, «оно»), крестик или галочка, штамп ФАКТ / ПО ОЦЕНКАМ / ВЫДУМКА с источником | по времени `at`, `until` |
| `RuleCard` | красная булавка с номером, ПРАВИЛО, правило на бумаге | `n={2} text="НЕ ОТВЕЧАЙ НА *СВОЁ ИМЯ*"` |
| `EndCard` | вопрос, список правил, «пиши номер в комментариях», что дальше | `items=[…] next="ЧАСТЬ 5 ЗАВТРА"` |
| `CoverA` | обложка 1080×1920 в том же стиле | `hook={['ОН УЖЕ', '*ВНУТРИ*']}` |

Всё время в секундах; в настоящем ролике оно берётся из голоса (`W('слово')`, `L(i).start`), как в остальных роликах.
Субтитры по словам: `CaseSubs` из Kit.

## Решение для тебя: цвет толстовки

На листе два варианта (набор_shorts_1.jpg, третья панель). **Рекомендую серый** с красными шнурками: у героя
конкурента синяя куртка, а красные шнурки это красная нить на самом герое. Если нравится синий, это одна строка
(`HERO_A_NAVY`). Ролик про сон остаётся с охристой толстовкой.

## Грамматика Short (из разбора конкурента и наших правил)

1. 0,0 с: голос сразу, первая фраза называет ситуацию и правило. Герой в кадре с первого кадра.
2. Каждые 2…3 с новый элемент: плашка, реплика, крестик, смена эмоции или позы, наезд камеры.
3. Фон меняется раз в 5…10 с; 3…4 декорации на ролик.
4. Прогресс-нить сверху с первой секунды; на каждое правило карточка.
5. Самый страшный момент: герой уходит в тень (`shadow`), после удара звука тишина.
6. Поворот в последние 10…15 с; финальная карточка 5…8 с.
7. Темп речи 2,2…2,4 слова в секунду (у нас сейчас 1,6…2,2).
8. Хоррор и «изнутри» в одном ролике не смешиваем.

## Сколько занимает один Short (оценка, проверим на первых пяти)

| Этап | Время |
|---|---|
| Сценарий 250…300 слов и `lines.json` | 30…40 мин |
| Озвучка и тайминги (Lumean + whisper) | 5…10 мин |
| Сцены из набора по словам | 40…60 мин |
| Звук (cues по словам) | 15…20 мин |
| Стоп-кадры, правки | 15 мин |
| Рендер 2-минутного Short на ноутбуке | 3…4 мин (демо 22 с: 52 с со сборкой) |
| **Итого** | **около 2…2,5 часа моей работы**, твоего времени около 5 мин (просмотр и TikTok) |

Новая декорация, которой нет в наборе, добавляет около часа; поэтому набор пополняется по одной декорации за раз
(следующие: лифт, двор с фонарём, ванная, улица у подъезда).
