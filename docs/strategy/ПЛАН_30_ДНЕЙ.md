на трёх площадках; записать реальное время производства; найти по данным формат, который цепляет; набрать подписчиков
для партнёрской программы VK Видео.

## 2. Формат на месяц

1. **Пилот: «7 дней без сна: что происходит с телом каждый день»**, 10…12 минут, 16:9. Главы по дням, отметки
   ФАКТ / ПО ОЦЕНКАМ / ВЫДУМКА, реальные случаи. Выходит на YouTube и в **VK Видео** (там это видео приносит деньги
   после порога). Исследование уже есть: docs/sleep-deprivation/research.md.
2. **Shorts «Если…» с правилами:** бытовой хоррор, 60…130 с, на наборе Shorts. Свои темы (ТЕМЫ.md), без тем конкурента.
3. **«Курьер уже внутри»:** часть 4, часть 5, финал сезона. Курьерскую тему 30.10 взял и конкурент, отличаемся героем,
   сквозным сюжетом и нитью.
4. **«Изнутри» короткие:** наука 45…70 с (рентген, нить, табло времени), без хоррора в том же ролике.
5. **Нарезка пилота:** «День 1…7 без сна», вертикальные версии сцен пилота, 7 Shorts.

Каждый Short выходит одним файлом на YouTube Shorts, TikTok и VK Клипы.

## 3. Темп: от 2 до 5 Shorts в день

| Неделя | Shorts в день | Shorts за неделю | Условие перехода на следующую ступень (проверка в воскресенье) |
|---|---|---|---|
| 1 (2…8.11) | 2 | 14 | все вышли в срок, мой цикл на Short не дольше 2 часов |
| 2 (9…15.11) | 3 | 21 | то же и не дольше 1,5 часа; медиана просмотров за 48 часов не падает |
| 3 (16…22.11) | 4 | 28 | не дольше 1,2 часа; досмотр не падает; YouTube загружается через API |
| 4 (23…29.11) | 5 | 35 | итог месяца решает темп декабря |

Если условие не выполнено, остаёмся на той же ступени неделю; если выполнено с трудом, тоже остаёмся.
Максимум за месяц около 100 Shorts, минимум (2 в день весь месяц) около 58.

**Как дойти до 5 в день:**
- серии по 3…5 Shorts на одной декорации и одной теме недели (одна новая декорация в неделю, не больше);
- нарезка пилота: 7 Shorts из готовых сцен, около часа на каждый;
- шаблон сцен по словам: плашки, карточки правил и прогресс расставляются по таймингам голоса, вручную только
  эмоции, позы и камера;
- рендер ночью пакетом: 5 Shorts по 2 минуты это около 20 минут на ноутбуке.

**Почему не сразу 5:** набор новый, первые ролики покажут реальное время и слабые места; при 5 в день без проверки
растёт риск однотипных роликов (YouTube не берёт в программы каналы с массовым однотипным контентом, а зрители
пролистывают приевшуюся формулу, это видно у конкурента).

## 8. Подключение к YouTube (один раз, делаешь ты)

Ключи и токены в чат не присылай: они кладутся в файл `.env` на ноутбуке (в git не попадает), я читаю их оттуда.

1. console.cloud.google.com: создать проект, например «krasnaya-nit».
2. APIs & Services, Library: включить **YouTube Data API v3** и **YouTube Analytics API**.
3. OAuth consent screen: тип External, свою почту в тестовые пользователи. Затем **Publish app** (статус In production),
   иначе доступ слетает каждые 7 дней. Предупреждение «Google не проверил это приложение» нормально: приложение твоё.
4. Credentials, Create credentials, OAuth client ID: тип **Web application**, в Authorized redirect URIs добавить
   `https://developers.google.com/oauthplayground`.
5. Открыть developers.google.com/oauthplayground, шестерёнка справа, «Use your own OAuth credentials», вставить
   Client ID и Client secret. Слева в поле областей ввести через пробел:
   `https://www.googleapis.com/auth/youtube.upload https://www.googleapis.com/auth/youtube.readonly https://www.googleapis.com/auth/yt-analytics.readonly`,
   нажать Authorize APIs, войти и выбрать канал «Красная Нить», затем Exchange authorization code for tokens и
   скопировать Refresh token. Эти права дают только загрузку, чтение и аналитику; удалять ролики и менять канал я не смогу.
6. В `.env` на ноутбуке добавить три строки: `YT_CLIENT_ID=...`, `YT_CLIENT_SECRET=...`, `YT_REFRESH_TOKEN=...`
   (`notepad .env` в папке проекта).
7. Я делаю пробную приватную загрузку и тестовый отчёт; пробный ролик потом удаляешь ты в Studio.

Загрузка через API без аудита Google публичная (документация videos.insert от 15.10.2026), лимит 100 загрузок в день.
TikTok через API без проверки публикует только приватно, поэтому TikTok вручную; VK выдаёт API загрузки видео по
запросу в поддержку, до этого тоже вручную.

## 10. Недельный отчёт: метрики и пороги

Пороги это гипотезы для диагностики; решения не по одному ролику.

| Метрика | Сигнал провала | Что делаем |
|---|---|---|
| CTR обложки длинного после 1 000 показов | ниже 3 % | новая обложка и название, тест в Studio |
| Удержание первых 30 секунд длинного | уходит больше половины | новое вступление: финал вперёд и вопрос |
| Средний процент просмотра длинного | ниже 25 % два выпуска подряд | короче главы, загадка раньше |
| Shorts: досмотр | в среднем меньше 70 % или большинство пролистывает | новая первая фраза и первый кадр |
| Просмотры Shorts за 48 часов | медиана недели ниже прошлой | не повышаем темп, меняем темы и упаковку |
| Подписки на 1 000 просмотров | падают две недели подряд | больше сериалов и концовок с причиной подписаться |
| Производство | Short дольше 2 часов или срыв слота | остаёмся на ступени, упрощаем сцены |
| Переход из Shorts в длинное | прироста нет | Shorts как отдельный формат, без расчёта на воронку |

Данные: просмотры, часы, подписки, источники трафика через YouTube Analytics API; показы и CTR обложек через
YouTube Reporting API (проверю в день 0); «Просмотрели или пролистнули» и время активности зрителей только в Studio:
раз в неделю ты присылаешь скриншоты вкладок «Охват» и «Аудитория». VK и TikTok: скриншоты статистики раз в неделю.

## 12. Риски

- **Однотипность при 5 в день:** у каждого Short свой сценарий, своя расстановка и поворот; одна формула не больше
  половины роликов недели.

- **VK и синтезированный голос** (п. 4.2.21 правил): риск для монетизации, решили пробовать и смотреть.
- **Моё время:** при 4…5 Shorts в день и длинном в ту же неделю нужны ежедневные сессии; если сессий меньше, темп ниже.
- **Медицинские темы:** никаких советов «как не спать», плашка «НЕ ПОВТОРЯЙ ЭТО», источник к каждому утверждению.
