# Звуковой дизайн

Файлы:
- генератор `_tmp/sleep/make_cues.py`, из него `src/toon/episodes/sleep.cues.json`;
- сведение `scripts/sfx.py` (без изменений), результат `public/sleep/mix.wav`, −14 LUFS;
- голос `_tmp/sleep/voice_final.wav`, паузы вставлены `scripts/voice_pauses.py`.

## Слои

| Слой | Чем сделан |
|---|---|
| Голос | Николай, одна запись, паузы под события: после строк 11 (+0,3 с), 14 (+0,4 с), 16 (+3,4 с черноты), 17 (+0,6 с), 20 (+0,4 с) |
| Атмосфера | тон комнаты `v_room_bed` (с дырами на провалы микросна), гул машины `sl_car_hum`, птицы `sl_birds` |
| Музыка | тональные аккорды `sfx.py` по актам: тёмный низкий (крючок), тёплый мажор (день 1), напряжённый минор (сутки и микросон), неустойчивый кластер (искажения), низкий за рулём, почти тишина (день 7), тёплое разрешение (после сна) |
| Фоли | тиканье, банка, зевок, печать, бумага, уведомления, удар телефона, вдох, стук клавиш, глитч, мерцание лампы, сердце, обратный нарастающий звук, гудок, проезд машины, выдох |
| Синтез | перезвон на старте, сигнал «жми», щелчок и низкий зуммер позднего нажатия, щелчки проходов по строке, низкие удары |

Новые звуки сгенерированы через Lumean (ElevenLabs SFX) и лежат в `public/sfx/sl_*.opus`:
- `sl_yawn`, `sl_can_open`, `sl_car_hum`, `sl_horn`, `sl_pass`, `sl_birds`.

Остальные взяты из библиотеки проекта. Зуммер не сгенерировался (ошибка сервиса), заменён синтезом.

## Правила, по которым выставлены уровни

Замер: мгновенная громкость EBU R128 по каждому событию против голоса.
- **Под речью** эффект минимум примерно на 7…8 LU тише голоса.
- **В паузе** эффект не громче средней речи минус 3 LU.
- **Гудок** (кульминация) примерно на уровне громких мест голоса и заканчивается до следующей фразы.

Первая версия сведения нарушала правила, исправлено замером:

| Звук | Было | Стало |
|---|---|---|
| Гудок | +14,8 LU к речи | примерно на уровне громких мест голоса, в паузе |
| Зевок | −1,9 LU поверх речи | перенесён в паузу, тише |
| Глитч | на уровне речи | −9 LU |
| Стук клавиш, уведомления, удар телефона, банка | −4…−7 LU | −8…−10 LU |

Итоговые замеры по готовому видео: production-notes.md.
