# Публикация

## Название (3 варианта)

1. **Что будет, если не спать 7 дней?** (рекомендую: совпадает с вопросом в первой секунде и с поисковым запросом)
2. 7 дней без сна: что происходит с мозгом
3. Почему нельзя не спать неделю

## Описание

По правилу канала: название ролика, максимум один вопрос по теме, хештеги. Сюжет не пересказываем, тире нет.

TikTok:
```
Что будет, если не спать 7 дней?
А сколько ты спал этой ночью?
#чтоесли #сон #мозг #наука #анимация
```

YouTube Shorts: тот же текст, в конце `#shorts`.

## Обложка

- **Файл:** `out/covers/sleep_deprivation_cover.png` (1080×1920, композиция `SleepDeprivationCover`).
- **Идея:** лицо героя на седьмые сутки (красные глаза, мешки, растрёпанные волосы) в холодном свете экрана: главный объект
  читается мгновенно даже в маленьком размере.
- **Текст:** «ЧТО БУДЕТ, ЕСЛИ НЕ СПАТЬ 7 ДНЕЙ?», «7 ДНЕЙ?» красным.
- **Композиция:**
  - заголовок в три строки в верхней трети, по оси x 500, внутри безопасной зоны;
  - под заголовком лицо крупным планом, глаза примерно на середине кадра;
  - низ без текста (там интерфейс платформы).
- **Для YouTube:** обложку Shorts можно выбрать только из кадров видео. Первый кадр ролика почти совпадает с обложкой
  (то же лицо, табло «168 Ч»), его и выбрать.

## Первый кадр

Кадр 0 ролика: лицо седьмого дня крупно и красное табло «БЕЗ СНА 168 Ч, ДЕНЬ 7». Без затемнения, голос с 0,1 с.
Субтитров в кадре 0 ещё нет, поэтому он годится как превью.

## Закреплённый комментарий

```
Почти все эффекты из ролика проходят после нормального сна. Источники: обзор Waters и соавторов 2018 года
(Frontiers in Psychiatry), материалы NIOSH (CDC) и NHLBI. Повторять эксперимент не нужно.
Сколько часов ты обычно спишь? Пиши цифрой.
```

## Что не обещаем

Ролик не утверждает, что на седьмой день человек умирает, и не даёт точных часов появления симптомов; заголовок и обложка
этого тоже не обещают.
